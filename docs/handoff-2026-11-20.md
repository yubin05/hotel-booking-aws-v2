## 3. 남은 순서 (사용자가 Git Bash에서 실행, 회차마다 결과를 받아 기록)

```bash
cd /c/dev/hotel-booking-aws-v2
aws login --profile admin                        # 1시간마다 다시. 기본 프로필도 aws login (만료됨)

# ① 깨진 배포 3회차 다시 (무효 회차가 22:35쯤 끝난 뒤)
bash drill/fault.sh deploy; echo "종료 코드 $?"      # 이제 0이어야 함

# ② 옛 환경 내리기 (측정 사이에, 이 순서)
aws login
cd infra/global && terraform plan && date && terraform apply && date      # 발생기 WAF 예외 빼기(IP 세트 1 삭제 + 웹 ACL 1 변경 예상)
cd /c/dev/hotel-booking-app/legacy && terraform plan -destroy -var is_load_test=true && date && terraform destroy -var is_load_test=true && date   # 19
cd iam && date && AWS_PROFILE=admin terraform apply && date               # 1 to destroy

# ③ DB 이중화 → DB 장애 조치 3회 → AZ 장애 3회
cd /c/dev/hotel-booking-aws-v2/infra/seoul
terraform plan -var multi_az=true && date && terraform apply -var multi_az=true && date   # NAT · EIP · 경로 추가 + RDS 1 change (변환 시간 미확인)
cd /c/dev/hotel-booking-aws-v2
bash drill/fault.sh rds && bash drill/fault.sh rds && bash drill/fault.sh rds; echo "종료 코드 $?"
aws login --profile admin                        # AZ는 10분 막으므로 직전에 새로
bash drill/fault.sh az; echo "종료 코드 $?"         # × 3. 중간에 끊기면: bash drill/fault.sh az-undo drill/results/fault-az-<시각>

# ④ 다 끝나면 내리기: global → 서울 (multi_az로 올렸으면 destroy 그대로), Grafana 공유 Pause
```

- 회차마다 보고서 두 표 + "회복 순서" 줄을 받아 `docs/experiments/faults.md` 결과 절에 표로 적는다(태스크 · 배포 절 모양). apply · destroy 시각은 03 결과 기록 표에
- 4단계 예측은 faults.md 표(사용자 칸은 "Claude와 같음"으로 받음)

## 4. 오늘 고친 측정 도구 버그 (모두 main에 push)

| 증상 | 원인 | 고침 |
|---|---|---|
| `&&` 연속 실행이 회차 뒤 멈춤, 종료 코드 1 | EXIT trap 첫 `kill`이 이미 끝난 기록기에 실패 + `set -e` → 정리 코드 중단 | `kill ... \|\| true` (깨진 리비전 해제 · AZ 되돌리기도 이 때문에 안 돌 수 있었음) |
| 회차 시작 확인에서 바로 끝남 | 앞 회차 직후 대체 태스크 정리 중 | 태스크 2 · 정상 2 · **배포 1개**가 될 때까지 최대 5분 기다림 |
| 쓰기가 전부 409 | writer가 회차마다 같은 객실 · 날짜 | 회차마다 무작위 숙소 페이지 · 날짜 구간(`page=` `day0=`가 writer.log 첫 줄에) |
| 시간 초과가 최대 5초 늦게 찍힘, 403 · 429가 정상 쪽, 기록 없음이 "오류 0" | drill-report 판정 | 새 판정 표 추가(보낸 시각 기준, 응답 분류, 미측정 구분, ECS 시작 → ALB 등록 순서). 기존 표 값은 그대로 |
| 쿠폰 준비(가입 1,000명 약 7분)가 T까지 안 끝남 | AWS에서 가입이 로컬보다 느림(bcrypt) | T = 시작 + 13분, 회차 간격 25분, 묶음은 T 13분 전까지 기다림 |
| 회차 끝 관리자 세션 만료 | aws login 1시간 | run-coupon.sh가 끝에서 끊겼으면 로그인 창을 열고 cw-metrics · 보고서까지 이어 감 |
