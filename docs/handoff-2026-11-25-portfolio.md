## 4. 새로 알게 된 것 (카드 후보)

- **로그인이 약한 고리:** 서버 8대에서도 p95 1.4 ~ 3.8초. 비밀번호 확인(scrypt, OWASP 최소 설정) 비용 → 보안은 낮추지 않고 대책을 따로
- **매시 정각 약 13초 정지:** 11:00 · 13:00 · 14:00 · 15:00 모두 HH:00:01 ~ 14초 p95 4 ~ 5초, :03 ~ :05초 503 약 800건. 원인 미확정(앱 · 인프라 정각 작업 없음, DB 로그에도 없음)
- **체감은 측정 위치(네트워크)에 크게 좌우:** 학원 PC 직접 체감 첫 화면 5 ~ 9초 · 결제 18 ~ 28초인데, 부하 없을 때 HAR(15:31)도 새 도메인마다 DNS 5 ~ 6초 + 연결 5 ~ 6초(서버 대기 0.1초 미만). 집 측정으로 확정 예정
- **개선 1건 반영:** 글꼴을 외부 CDN(jsDelivr)에서 앱 안으로(앱 `0d902c8`). 학원 HAR에서 글꼴 CSS 연결에만 3.2초가 들던 요청이 사라짐

## 5. 바꾸지 않을 것

- 11-20 숫자 자체(500 → 3,000명, 쿠폰 1,000명 3회씩)는 지우지 않는다. 이름 · 단서만 바로잡는다
- 쿠폰 3,000명 시험은 아직 안 했다(최대 대수 확정 뒤)
